# ร้านขายถูกที่นี่ชุมแพ (Chum Phae Store) - Source Code
**Revision: 2026.10.26-rev2** (Deploy Verified)

ยินดีด้วยครับ! นี่คือไฟล์ Source Code ฉบับสมบูรณ์ที่ผ่านการตรวจสอบความพร้อมสำหรับ Deploy เรียบร้อยแล้ว

## 🚀 วิธีนำขึ้น GitHub & Deploy บน Vercel แบบ 0 Error

### ขั้นตอนที่ 1: แตกไฟล์ ZIP
1. คลิกขวาที่ไฟล์ `chumphae-store-source.zip`
2. เลือก **Extract All... (แตกไฟล์ทั้งหมด)**

### ขั้นตอนที่ 2: อัปโหลดขึ้น GitHub
1. เข้าเว็บ https://github.com แล้วกดปุ่มสีเขียว **"New"**
2. ตั้งชื่อ Repository เช่น `chumphae-store` แล้วกด **"Create repository"**
3. คลิกข้อความ **"uploading an existing file"**
4. ลากไฟล์และโฟลเดอร์ทั้งหมด (src, api, public, package.json, vite.config.ts ฯลฯ) วางลงในหน้าเว็บ
5. พิมพ์ Commit ว่า `Deploy Revision 2026.10.26-rev2` แล้วกด **"Commit changes"**

### ขั้นตอนที่ 3: Deploy ฟรีบน Vercel (เปิดเว็บจริงใช้งานได้ทันที)
1. เข้าเว็บ https://vercel.com แล้วล็อกอินด้วย GitHub
2. กดปุ่ม **"Add New..." -> "Project"**
3. เลือก Repository `chumphae-store` แล้วกด **"Import"**
4. กดปุ่ม **"Deploy"** ได้ทันที (ระบบมีไฟล์ vercel.json และ build script พร้อมใช้งาน 100% ไม่ต้องแก้ค่าใดๆ)
5. เมื่อเสร็จสิ้น คุณจะได้โดเมนจริง เช่น `https://chumphae-store.vercel.app` ใช้งานได้ตลอด 24 ชั่วโมง
